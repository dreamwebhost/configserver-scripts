To install or upgrade cmm, obtain the package from a trusted source, verify it,
then run the following from the extracted cmm directory as root:

sh install.sh

Then login to WHM and scroll to the bottom of the left hand menu and you should see "ConfigServer Mail Manage"


To uninstall from the extracted cmm directory as root:

sh uninstall.sh
